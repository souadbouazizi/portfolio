# Markdown
Flexbox is a powerful layout model in CSS that allows developers to create flexible and responsive designs with ease.

### Why Flexbox?
Unlike traditional layout methods like floats or inline-block, Flexbox enables dynamic resizing and alignment of elements without worrying about screen size or content overflow.

### Key Concepts:
- **Flex Container**: Set by `display: flex;`.
- **Main Axis & Cross Axis**: Flexbox works along two axes; you can control direction using `flex-direction`.
- **Justify Content**: Controls alignment along the main axis.
- **Align Items**: Controls alignment on the cross axis.

### Example:
```css
.container {
  display: flex;
  justify-content: space-between;
  align-items: center;
}
